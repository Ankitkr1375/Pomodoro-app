# ⏱️ Pomodoro Timer App

A simple and effective **Pomodoro timer** built using **Python** and **Tkinter**. This app helps you boost productivity by following the Pomodoro Technique — work in focused intervals followed by short breaks.

---

## 📌 Features

- ⏰ 25-minute work sessions
- ☕ 5-minute short breaks
- 😴 15-minute long breaks after every 4 work sessions
- 🖥️ Intuitive Tkinter GUI
- 🔁 Automatic transition between sessions
- 🔔 Sound notifications (optional)

---

## 🚀 Getting Started

### ✅ Prerequisites

Make sure you have **Python 3.x** installed.
